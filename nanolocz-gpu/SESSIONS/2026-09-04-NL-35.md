## Key Design Decisions

1. **Morphological Approach**: Used grey erosion/dilation with structural elements for fast approximate tip estimation
2. **Optimization Framework**: L-BFGS-B optimizer with flexible regularization terms
3. **Richardson-Lucy**: Implemented with TV regularization using gradient magnitude (avoided scipy.ndimage.divergence which is not available)
4. **Wiener Filter**: FFT-based implementation with automatic SNR estimation from image statistics
5. **Validation Metrics**: Comprehensive set including aspect ratio, volume, sharpness (0-1), rotational symmetry, and physical plausibility checks
