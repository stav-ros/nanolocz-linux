## Usage

### From Napari
1. Open Napari: `napari`
2. Go to Plugins → NanoLocz → Make NanoLocz Widget
3. Dock widget appears with full AFM workflow controls

### Programmatic
```python
import napari
from nanolocz.plugins import NanoLoczWidget

viewer = napari.Viewer()
widget = NanoLoczWidget(viewer)
viewer.window.add_dock_widget(widget, area='right')
napari.run()
```

## Known Limitations (NL-41a vs NL-41b)
NL-41a (current) provides minimum viable plugin. NL-41b will add:
- SPM/JPK/IBW/ASD proprietary format readers
- Advanced LAFM reconstruction with GPU acceleration
- FRC resolution visualization plots
- Dynamic traces over time
- 3D reconstruction volume rendering
- Multiple synchronized views
- ROI measurements panel
- Batch processing from GUI
- GPU selection controls
- Session/config persistence across restarts

## Architecture Notes
- Plugin calls core functions directly (no duplicated logic)
- Shared `PipelineConfig` ensures CLI/GUI parameter consistency
- Worker threads needed for NL-41b to prevent UI blocking
- React dashboard remains separate (documentation/control plane)
- Clear boundary: Browser ≠ Python backend execution
