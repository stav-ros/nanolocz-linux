## Work performed

### 1. CLI module structure created
Created `nanolocz/cli/` package with:
- `__init__.py` - Package initialization
- `main.py` - Argparse setup with subparsers for all commands
- `preprocess.py` - Preprocessing subcommand (leveling, filtering, scar removal)
- `detect.py` - Particle detection subcommand
- `track.py` - Single-particle tracking subcommand
- `lafm.py` - LAFM reconstruction and FRC subcommand
- `batch.py` - Batch processing with job queue management
- `utils.py` - Shared utilities (config loading, path expansion, PipelineConfig)

### 2. Entry point configured
- Added `nanolocz = "nanolocz.cli.main:main"` to `[project.scripts]` in `pyproject.toml`
- Verified with `pip install -e .` and `nanolocz --help`

### 3. Subcommands implemented

#### `nanolocz preprocess`
- Input: AFM files (.gwy, .h5-jpk, .spm, .jpk, .ibw, .asd, .tiff)
- Output: .zarr file with preprocessed movie
- Options: leveling method, filter type, filter sigma, scar removal, GPU flag, precision

#### `nanolocz detect`
- Input: Preprocessed .zarr file
- Output: .zarr file with detected particles
- Options: threshold, min-distance, prominence, mask, GPU flag

#### `nanolocz track`
- Input: Detected particles .zarr
- Output: .zarr file with tracks
- Options: max-displacement, memory (gap closing), GPU flag

#### `nanolocz lafm`
- Input: Tracked particles .zarr
- Output: .zarr file with LAFM splat and FRC resolution
- Options: pixel-size, sigma, frc-threshold, GPU flag

#### `nanolocz batch`
- Input: Multiple files or directory with glob patterns
- Output: Directory with results
- Options: config file, pipeline stage selection, parallel jobs, continue-on-error, dry-run
