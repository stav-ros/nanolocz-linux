## Key Features Implemented

### Reconstruction Algorithms
1. **Weighted Back-Projection**: Fast reconstruction with weight normalization
2. **SIRT**: Iterative refinement with convergence tracking
3. **Gold-Standard Split**: Unbiased particle splitting for FSC validation

### Resolution Validation
- FSC computation with shell-based frequency analysis
- Threshold detection (0.143 cryo-EM, 0.5 AFM)
- Half-map independent reconstruction

### Integration Points
- Accepts `ParticleStack` from NL-32/NL-34
- Supports 3D (particles, H, W) and 4D (particles, frames, H, W) stacks
- Optional CTF correction framework
- GPU acceleration path via CuPy

## Technical Decisions

1. **Euler Angle Convention**: Z-Y-Z convention for rotation matrices
2. **Interpolation**: Scipy ndimage for coordinate transforms (order=1 linear)
3. **Forward Projection**: Maximum intensity projection after rotation
4. **Convergence Metric**: Pearson correlation between iterations
5. **Positivity Constraint**: Enforced in SIRT (volume ≥ 0)

## Known Limitations

1. **GPU Implementation**: Currently falls back to CPU; full CuPy implementation pending ASTRA toolbox integration
2. **Isosurface Mesh**: Stub implementation; requires scikit-image marching cubes
3. **CTF Correction**: Framework in place but not fully implemented
4. **Memory Efficiency**: Large volumes may require chunking for production use
