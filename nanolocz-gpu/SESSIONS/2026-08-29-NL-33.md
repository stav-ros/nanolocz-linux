## Specification

Created `SPEC/NL-33-pca-hdbscan.md` with full acceptance criteria:

1. **PCA dimensionality reduction** — Reduce high-dimensional substack data while preserving variance
2. **Component selection heuristics** — Automatic selection via Kaiser criterion, elbow detection, or cumulative variance
3. **HDBSCAN clustering** — Density-based clustering with automatic cluster count and noise handling
4. **Classification pipeline** — Combined PCA + HDBSCAN workflow returning `ClassificationResult`
5. **Visualization utilities** — Scree plots, 2D/3D cluster scatter plots, cluster size distributions
6. **GPU acceleration** — CuPy-accelerated PCA via SVD with CPU fallback
7. **Integration** — Export from `nanolocz.core.classification`, compatible with Zarr storage

## Implementation Plan

### Core Module (`nanolocz/core/classification.py`)
- `reduce_dimensions_pca(data, n_components)` — PCA dimensionality reduction
- `select_n_components(variance_ratios, method)` — Automatic component selection
- `cluster_hdbscan(coords, min_cluster_size, min_samples)` — HDBSCAN clustering
- `classify_particles(particle_stack, ...)` — End-to-end classification pipeline
- `ClassificationResult` dataclass — Structured results with labels, probabilities, metadata
- Visualization helpers: `plot_scree()`, `plot_clusters_2d()`, `plot_cluster_sizes()`

### GPU Module (`nanolocz/gpu/classification.py`)
- `reduce_dimensions_pca_gpu()` — GPU-accelerated PCA using CuPy SVD
- Batched processing for large datasets
- CuPy backend integration via `BackendContext`

### Tests (`tests/test_classification_nl33.py`)
