Core GPU AFM simulation module implementing:

#### Functions Implemented

**`compute_height_field_gpu(bead_cloud, shape, pixel_size, z_scale=1.0)`**
- Generates height field from bead cloud molecular model
- Parameters:
  - `bead_cloud`: BeadCloud object with positions and radii
  - `shape`: Output image shape (height, width)
  - `pixel_size`: Physical pixel size in nm/pixel
  - `z_scale`: Optional scaling factor for height values
- Returns height field as GPU array (float32/float64)
- Uses vectorized distance computations
- Handles overlapping beads correctly (maximum height)

**`convolve_tip_gpu(height_field, tip_radius, tip_angle=0.0, elliptical=False)`**
- Simulates tip-sample convolution effect
- Models parabolic or elliptical AFM tip geometry
- Parameters:
  - `height_field`: Input surface height map
  - `tip_radius`: Tip apex radius in pixels
  - `tip_angle`: Optional tip tilt angle (radians)
  - `elliptical`: Use elliptical vs circular tip model
- Returns convolved height field (dilated by tip shape)
- Uses morphological dilation with tip kernel
- Accounts for finite tip size broadening effects

**`add_thermal_noise_gpu(height_field, temperature=300.0, drift_velocity=0.0)`**
- Adds thermal drift artifacts to simulated image
- Models slow sample drift during scanning
- Parameters:
  - `height_field`: Input height map
  - `temperature`: Temperature in Kelvin (affects noise amplitude)
  - `drift_velocity`: Drift rate in pixels/second
- Returns height field with thermal artifacts
- Implements line-by-line drift accumulation
- Optional random walk component

**`add_shot_noise_gpu(height_field, intensity_scale=1000.0)`**
- Adds Poisson shot noise to simulate detection statistics
- Models counting statistics in height measurement
- Parameters:
  - `height_field`: Input height map
  - `intensity_scale`: Scaling factor for noise amplitude
- Returns height field with shot noise
- Uses proper Poisson distribution sampling
- Preserves non-negative heights

**`add_scan_artifacts_gpu(height_field, line_skip_prob=0.01, spike_prob=0.001)`**
- Adds realistic scan line artifacts
- Models common AFM imaging artifacts:
  - Line skips (missing data rows)
  - Spike artifacts (sudden height jumps)
  - Scan noise (high-frequency line variations)
- Parameters:
  - `height_field`: Input height map
  - `line_skip_prob`: Probability of line skip per row
  - `spike_prob`: Probability of spike artifact per pixel
- Returns height field with artifacts
- Configurable artifact rates for realism tuning

**`simulate_afm_image_gpu(bead_cloud, shape, pixel_size, tip_radius, temperature=300.0, add_artifacts=True)`**
- Complete AFM simulation pipeline combining all above functions
- Executes full workflow:
  1. Compute height field from bead cloud
  2. Apply tip-sample convolution
  3. Add thermal noise/drift
  4. Add shot noise
  5. Optionally add scan artifacts
- Parameters:
  - `bead_cloud`: Molecular model (BeadCloud)
  - `shape`: Output image dimensions
  - `pixel_size`: Physical scale (nm/pixel)
  - `tip_radius`: Tip apex radius (pixels)
  - `temperature`: Simulation temperature (K)
  - `add_artifacts`: Include realistic artifacts
- Returns final simulated AFM image
- Single function call for complete simulation

## Physical Background

### AFM Image Formation
AFM images are formed by:
1. Sharp tip scans across sample surface
2. Tip-sample interaction measured (force, tunneling current)
3. Feedback maintains constant interaction
4. Height recorded at each pixel

### Tip-Sample Convolution
Finite tip size causes:
- Feature broadening (lateral resolution limit)
- Steep slope averaging
- Deep narrow feature inaccessible
- Modeled as morphological dilation

### Noise Sources in AFM
- **Thermal drift**: Slow sample movement due to temperature
- **Shot noise**: Statistical fluctuations in detection
- **Scan artifacts**: Electronic/mechanical imperfections
- **Vibration**: External mechanical disturbances

### Simulation Applications
- Algorithm validation with known ground truth
- Parameter optimization before experiments
- Training data for machine learning
- Educational demonstrations
