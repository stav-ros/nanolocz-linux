## Summary

Implemented the CPU core port foundation with two critical modules:

### NL-14: Leveling Algorithms
**File:** `nanolocz/core/leveling.py`

Implemented functions:
- `line_leveling()` - Row-by-row median subtraction with reference line preservation
- `plane_leveling()` - Least-squares plane fitting (z = ax + by + c) with R² metrics
- `weighted_multi_plane_leveling()` - Multi-region leveling with smooth blending
- `level_image()` - Unified interface for all leveling methods
- `batch_level_movie()` - Process 3D movie stacks frame-by-frame

Key features:
- Mask support for excluding invalid pixels
- Weighted least squares for robust fitting
- Goodness-of-fit metrics (residual_std, r_squared)
- Distance-transform-based region blending

### NL-15: Filters, Masks, and Profiles
**File:** `nanolocz/core/filters.py`

Implemented functions:
- **Filtering:** `gaussian_blur()`, `median_blur()`, `uniform_blur()`
- **Gradients:** `compute_gradient()` (Sobel), `compute_laplacian()`
- **Masks:** `create_mask_from_threshold()`, `create_circular_mask()`, `create_rectangular_mask()`
- **Artifact removal:** `remove_scars()` for horizontal/vertical scan lines
- **Profiles:** `extract_profile()` (linear), `extract_radial_profile()`
- **Morphology:** `morphological_operations()` (erode, dilate, open, close)
- **Distance:** `distance_transform()`
