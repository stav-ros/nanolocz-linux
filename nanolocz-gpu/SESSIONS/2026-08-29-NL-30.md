# NL-30 — Per-frame drift estimation

## Outcome

Implemented comprehensive drift estimation and correction system in `nanolocz/core/drift.py` with both cross-correlation and particle-based methods.

## Deliverables

### Core Implementation (`nanolocz/core/drift.py`)
- **DriftResult dataclass**: Structured result container with validation for shifts, cumulative drift, method, and metadata
- **estimate_drift_xcorr()**: FFT-based phase correlation for sub-pixel drift estimation
  - Frame-to-frame or reference-based tracking
  - Sub-pixel precision via upsampling
  - Quality metrics (correlation peak sharpness)
  - Cumulative drift trajectory computation
- **estimate_drift_particles()**: Particle-based drift tracking
  - Integrates with `detect_particles()` from NL-16/NL-22
  - Particle matching between consecutive frames
  - Median displacement as robust drift estimate
  - Handles missing/partial detections gracefully
- **correct_drift()**: Drift correction application
  - Applies shift correction to movie frames
  - Supports interpolation for sub-pixel shifts
  - Preserves metadata and timestamps
  - Multiple correction modes (absolute, relative)
- **estimate_drift_xcorr_gpu()**: GPU-accelerated cross-correlation using CuPy FFT
  - Maintains parity with CPU implementation
  - Automatic fallback when CuPy unavailable

## Contract

- Input: Movie as 3D array (frames, rows, cols) or list of Frame objects
- Output: DriftResult with shifts (N, 2), cumulative_drift (N, 2), method identifier
- Cross-correlation: Phase correlation via FFT, sub-pixel via upsampling
- Particle-based: Requires detectable features, robust to outliers via median
- Correction: Interpolation-based, preserves frame metadata
- GPU acceleration: Optional, transparent fallback to CPU
