## Objective

Complete the file format reader suite by implementing support for additional AFM file formats:
- **NL-12**: `.spm` (NanoScope ASCII), `.jpk` (JPK HDF5), `.ibw` (Igor Pro binary wave)
- **NL-13**: `.asd` (RBM/ASD exports including trace-only files)

## Implementation Summary

### NL-12 Deliverables

#### `nanolocz/formats/spm_reader.py`
- **Function**: `read_spm(filepath, channel="height", frame="all")`
- **Features**:
  - ASCII matrix parsing with comment line metadata extraction
  - Regex-based metadata parsing (`# key=value` format)
  - Automatic pixel_size tuple construction from pixel_size_x/pixel_size_y
  - Rectangular data validation
  - Returns `(data: np.ndarray, metadata: dict)`
- **Test coverage**: `tests/test_io_nl12.py::test_spm_ascii_fixture_is_normalized`

#### `nanolocz/formats/jpk_reader.py`
- **Function**: `read_jpk(filepath, channel="topography", frame="all")`
- **Features**:
  - Thin wrapper around shared `read_h5jpk()` from `h5jpk_reader.py`
  - Sets format metadata to "JPK"
  - Reuses existing HDF5 JPK infrastructure from NL-11
- **Test coverage**: `tests/test_io_nl12.py::test_jpk_hdf5_fixture_reads_through_unified_opener`

#### `nanolocz/formats/ibw_reader.py`
- **Function**: `read_ibw(filepath, frame="all")`
- **Features**:
  - Optional `igor2` dependency (raises ImportError with helpful message if missing)
  - Binary wave loading via `igor2.binarywave.load()`
  - Always returns float64 dtype
  - Frame slicing support for 3D movies
  - Explicit error messages for corrupt/unsupported IBW files
- **Test coverage**: `tests/test_io_nl12.py::test_ibw_requires_optional_igor_reader`

### NL-13 Deliverables

#### `nanolocz/formats/asd_reader.py`
- **Function**: `read_asd(filepath, frame="all") -> tuple[np.ndarray, dict]`
- **Features**:
  - NumPy-compatible `.npz` container format for portable ASD interchange
  - Supports both 2D images and 1D trace-only files
  - JSON metadata serialization within NPZ archive
  - Automatic `trace_only` flag based on data dimensionality
  - Metadata normalization with defaults
  - Proper error handling for corrupted/unrecognized files
- **Helper**: `_normalise_metadata(raw, path, data)` for consistent metadata structure
- **Test coverage**: 
  - `test_asd_image_fixture_round_trip`
  - `test_asd_trace_only_fixture_is_preserved`
  - `test_asd_metadata_defaults_are_stable`

### Unified Opener Interface Integration

All readers integrate with `nanolocz.io.open_nanolocz()`:
- Read-only mode enforced for legacy formats
- Consistent metadata structure across all format readers
- Proper error handling for missing files and unsupported formats

## Architecture Notes

### Format Reader Pattern
All format readers follow the same pattern:
```python
def read_<format>(filepath, channel="<default>", frame="all") -> tuple[np.ndarray, dict]:
    # 1. Validate file existence and extension
    # 2. Parse data (ASCII/binary/container)
    # 3. Extract/normalize metadata
    # 4. Return (data, metadata) tuple
```

### Metadata Conventions
- `format`: Uppercase format identifier (e.g., "SPM", "JPK", "ASD", "IBW")
- `shape`: Data shape tuple
- `dtype`: NumPy dtype string
- `filepath`: Source file path
- `pixel_size`: Tuple of (x, y) pixel sizes in nm when available
- `trace_only`: Boolean for 1D ASD traces (NL-13 specific)

### Optional Dependencies
- `igor2` for IBW support is intentionally optional
- Clear ImportError message guides users to install if needed
- Allows core package to remain lightweight
