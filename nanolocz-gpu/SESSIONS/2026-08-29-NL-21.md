# NL-21 — Batched levelling kernel

## Outcome

Implemented `batch_line_leveling()` in `nanolocz/core/leveling.py` as the first GPU-kernel seam for batched movie processing. The operation accepts a `BackendContext`, uses its NumPy/CuPy array module and precision policy, computes per-frame/per-line masked medians without Python-level frame iteration, preserves the first line as the reference level, and returns CPU arrays for the stable public API.

## Contract

- Input must be a 3-D movie shaped `(frames, rows, columns)`.
- An optional 2-D boolean mask is broadcast across frames.
- Empty masked lines receive a zero offset rather than propagating NaNs.
- Offsets are reference-relative, matching `line_leveling()` semantics.
- CPU reference and high precision modes produce float64 output; mixed GPU mode may compute in float32 before transfer.
- Invalid movie dimensions and mask shapes raise `ValueError`.
