#### Functions Implemented

**`splat_gaussian_gpu(coordinates, amplitudes, sigma_x, sigma_y, shape, angles=None)`**
- Splats 2D elliptical Gaussians at specified coordinates
- Parameters:
  - `coordinates`: (N, 2) array of (y, x) positions
  - `amplitudes`: (N,) array of peak heights (default: 1.0)
  - `sigma_x`, `sigma_y`: Gaussian widths in pixels
  - `shape`: Output image shape (height, width)
  - `angles`: Optional rotation angles for each Gaussian (radians)
- Returns reconstructed image as GPU array
- Uses vectorized GPU operations for efficient splatting
- Supports per-localization elliptical parameters

**`splat_localizations_gpu(localizations, pixel_size=1.0, sigma_nm=5.0, shape=None)`**
- Convenience wrapper for localization data structures
- Converts physical coordinates (nm) to pixel indices
- Automatically determines output shape if not provided
- Uses isotropic Gaussians with fixed sigma
- Returns reconstructed super-resolution image

**`compute_frc_gpu(image1, image2, mask=None, num_bins=50)`**
- Computes Fourier Ring Correlation between two half-maps
- Implements gold-standard FRC for resolution estimation
- Parameters:
  - `image1`, `image2`: Two independent reconstructions (half-maps)
  - `mask`: Optional circular/soft mask to limit analysis region
  - `num_bins`: Number of radial frequency bins
- Returns tuple: (frequencies, frc_values)
- Uses CuPy's FFT for accelerated computation
- Applies proper normalization and background subtraction

**`frc_resolution(frequencies, frc_values, threshold=0.5)`**
- Extracts resolution from FRC curve at specified threshold
- Common thresholds:
  - 0.5: Standard resolution criterion
  - 0.143: "Gold standard" cryo-EM criterion
  - 0.33: Intermediate criterion
- Interpolates between frequency bins for sub-bin precision
- Returns resolution in same units as input frequencies
- Handles edge cases (no crossing, multiple crossings)

**`batch_splat_gpu(coordinates_list, amplitudes_list=None, sigma_x=2.0, sigma_y=2.0, shape=None)`**
- Batch processing for multiple localization sets
- Efficiently processes multiple reconstructions in sequence
- Parameters:
  - `coordinates_list`: List of coordinate arrays
  - `amplitudes_list`: Optional list of amplitude arrays
  - `sigma_x`, `sigma_y`: Fixed or per-set Gaussian parameters
  - `shape`: Common output shape for all reconstructions
- Returns list of reconstructed images
- Optimizes memory reuse across batch elements

## Technical Decisions

### Vectorized Gaussian Splatting
- Avoided per-particle loops by using broadcasting
- Pre-computes Gaussian kernels on regular grid
- More memory-efficient than naive approach
- Scales well to millions of localizations

### FFT-Based FRC
- Uses CuPy's highly optimized FFT implementation
- Computes ring averages in Fourier space
- Proper handling of Nyquist frequency
- Soft mask option to reduce edge artifacts

### Resolution Interpolation
- Linear interpolation between frequency bins
- More accurate than nearest-bin selection
- Handles both monotonic and non-monotonic FRC curves
- Returns NaN when no valid crossing found

## Scientific Background

### LAFM Reconstruction
Localization-based AFM reconstructs super-resolution images by:
1. Detecting particle positions in multiple AFM frames
2. Fitting precise coordinates (sub-pixel accuracy)
3. Splattering Gaussians at each position
4. Summing contributions to form final image

### Fourier Ring Correlation
FRC measures resolution by:
1. Splitting data into two independent halves
2. Reconstructing two half-maps
3. Computing correlation in Fourier space
4. Finding frequency where correlation drops below threshold
5. Converting frequency to spatial resolution

Common thresholds:
- 0.5: Traditional resolution criterion
- 0.143: Gold standard (cryo-EM convention)
- 0.33: Intermediate criterion for some applications
